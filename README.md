# 🎓 Student Management System

## 📖 Overview

The **Student Management System** is a beginner-friendly console application developed using **C++** by applying **Object-Oriented Programming (OOP)** concepts. The project is designed to simplify the process of managing student records, including academic details, grades, and CGPA calculations.

The application allows users to create, search, update, delete, and display student records through an interactive menu-driven interface. It also generates class reports containing student performance statistics.

This project helped strengthen my understanding of C++ programming, object-oriented design, functions, arrays, encapsulation, and data management.

---

# ✨ Features

- ✅ Add New Student Records
- ✅ Display All Students
- ✅ Search Student by Roll Number
- ✅ Modify Student Information
- ✅ Delete Student Record
- ✅ Calculate Student Percentage
- ✅ Automatic Grade Calculation
- ✅ Automatic CGPA Calculation
- ✅ Generate Class Report

# 🚀 How to Run

### Clone Repository

```bash
git clone https://github.com/uzaam07/Student-Management-System.git
```

Open the project using:

- Visual Studio Code
- CodeBlocks
- Dev C++
- CLion

### Compile

```bash

```

### Run


```bash

```
